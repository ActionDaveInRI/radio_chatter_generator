# Radio chatter

Simulated radio conversations with synthesized voices, environmental context, and experimental local language models.

[Open project](https://actiondaveinri.github.io/radio_chatter_generator/versions/tts_09.html) · [All projects](https://actiondaveinri.github.io/spaceship/) · [Versions](https://actiondaveinri.github.io/radio_chatter_generator/)

The recommended start is scripted `versions/tts_09.html`. All original snapshots live under `versions/`, and their old root URLs redirect to them. Language-model variants retain their original CDN/model dependencies; they have not been revalidated. Preview captured from tts_09 on 2026-09-27.
